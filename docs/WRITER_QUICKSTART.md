# Writer Quickstart

**BE Protocol Platform — Controlled Beta**  
Keep this sheet nearby during a session. Identity in analytics = pseudonym only.

## Login

1. Open the beta URL (default `http://localhost:5173`).
2. Sign in with your provided account (`AUTH_REQUIRED`).
3. Confirm you are in the correct organization (tenant).

## Create / open study

1. Open **Study workspace**.
2. Select or create the study for your package.
3. Confirm study key matches the intake case.

## Upload package

1. Upload Checklist / Synopsis / SmPC / prior protocol as available.
2. Missing docs stay **ABSENT** or **NOT_REQUIRED** — that is OK.
3. Do not upload patient identifiers, credentials, or personal contacts.

## Review extraction

1. Open extraction / Writer Review.
2. For each critical field, confirm value + source.
3. Classify: `CORRECT_AUTO` · `CORRECT_AFTER_REVIEW` · `MISSING` · `INCORRECT` · `CONFLICTING` · `N/A`.
4. Correction after review is **not** automatic success.

## Inspect evidence

1. Open provenance for critical fields.
2. Check source, location, excerpt, confidence.
3. Rate evidence: USEFUL / PARTIAL / INSUFFICIENT / WRONG_SOURCE.

## Resolve conflict

1. Open conflicts list.
2. Leave OPEN until you decide — system must not auto-resolve.
3. Record expected / detected / missed / false positive when asked.

## Approve decision

1. Review recommendations as suggestions only.
2. Approve, reject, or modify as **expert**.
3. AI cannot approve.

## Sample size & statistics

1. Review engine inputs/outputs.
2. Mark ACCEPTED / MODIFIED / REJECTED / BLOCKED.
3. Do not invent formulas.

## Generate protocol & preflight

1. Generate protocol draft.
2. Run preflight — fix CRITICAL blockers before FINAL.
3. Generate DOCX and open it yourself.

## Field-study feedback

1. On **Controlled beta** tab: run MANUAL timer, then ASSISTED timer (same pair).
2. After pair: record biggest saver, friction, least trusted, never-automate, etc.
3. Stop timers with the UI button — do not type estimated minutes.

## Need help?

Ask the beta operator. Do not bypass auth or sanitization gates.
