# Writer Beta Protocol

Short field protocol for controlled beta. No internal architecture required.

## Before session

1. Log in.
2. Confirm organization and study.
3. Confirm package is **sanitized** and assigned to you (pseudonym id).
4. Read `docs/WRITER_QUICKSTART.md` / first-session checklist if provided.

## Manual session (baseline)

1. Open **Controlled beta** → Session launcher.
2. Select REAL case → **Start MANUAL baseline**.
3. Work as usual **without** relying on system assistance for extraction/protocol (use only unavoidable infrastructure).
4. Click **Stop active timer** when done — do not type estimates.

## Assisted session

1. Same case, same writer, use the shown **pair id**.
2. **Start SYSTEM ASSISTED**.
3. Use workspace: extraction → conflicts → evidence → research → decisions → sample size → statistics → protocol → preflight → DOCX.
4. Classify corrections when asked.
5. **Stop** timer when finished.

## Feedback

After the pair, answer:

- biggest time saver  
- biggest friction  
- least trusted output  
- most useful feature  
- most frequent correction  
- missing feature  
- desired automation  
- what must stay human-controlled  

## Completion

1. Confirm both sessions show completed.
2. Do not ask AI to approve medical decisions.
3. Notify operator for backup/export if this was a scheduled beta day.
